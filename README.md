# Сложно сосредоточиться

Адаптивная статья о концентрации внимания. В меню «День» включает светлую тему,
«Неон» включает тёмную, а «Авто» следует системным настройкам.

Чтобы посмотреть страницу, откройте `index.html` в браузере.

[Репозиторий проекта](https://github.com/artemchuv/slozhno-sosredotochitsya-ad)
